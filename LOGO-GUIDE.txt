НА ВЕБСАЙТЕ (HTML):
──────────────────

1. Скопируйте SVG файл в папку /images/ вашего сайта
2. Вставьте в HTML:

   <img src="/images/logo-asc-prod.svg" alt="ASC•Prod" width="150" height="50">

   или для иконки:

   <link rel="icon" type="image/svg+xml" href="/images/logo-asc-prod-icon.svg">

3. Для использования в CSS:

   .logo { background-image: url('/images/logo-asc-prod-icon.svg'); }


В ДОКУМЕНТАХ (Word, LibreOffice):
─────────────────────────────────

1. Откройте документ
2. Меню → Вставка → Изображение
3. Выберите logo-asc-prod.svg (или вертикальный)
4. Перетащите нужный размер
5. Сохраните документ


НА ПЕЧАТЬ (полиграфия):
──────────────────────

1. Используйте logo-asc-prod-monochrome.svg для чёрно-белой печати
2. Используйте logo-asc-prod-vertical.svg для визиток, наклеек
3. Минимальный размер печати: 10mm × 10mm
4. Сохраните как PDF (File → Export as PDF)

   Настройки PDF:
   ├─ Color space: RGB или CMYK (спросите в типографии)
   ├─ Compression: ZIP
   └─ Quality: Maximum


В FIGMA (дизайн):
────────────────

1. Откройте проект в Figma
2. File → Place files or paste image
3. Выберите logo-asc-prod.svg
4. Логотип откроется как компонент
5. Масштабируйте как угодно (SVG сохранит качество)


В POWERPOINT / KEYNOTE:
─────────────────────

1. Слайд → Вставить → Изображение
2. Выберите logo-asc-prod.svg
3. Вставьте и масштабируйте
4. Сохраните презентацию

   ├─ Неправильно: Оранжевый логотип на жёлтом фоне
   └─ Правильно: Контрастный фон (чёрный/белый или синий)

🔄 ФОРМАТЫ КОНВЕРТАЦИИ
════════════════════════════════════════════════════════════════════════════════

Если нужен другой формат, вы можете конвертировать SVG:

SVG → PNG:
  1. Откройте logo-asc-prod.svg в браузере
  2. Правая кнопка → Сохранить изображение как
  3. Выберите PNG формат

SVG → PDF:
  1. Откройте в Adobe Illustrator или Inkscape
  2. File → Export as → PDF
  3. Сохраните

SVG → JPG:
  1. Откройте в браузере
  2. Откройте DevTools (F12)
  3. Скопируйте SVG код
  4. Вставьте в онлайн-конвертер (cloudconvert.com)
  5. Выберите JPG, конвертируйте
