# 📊 ASC•Prod Инструменты

Набор из четырёх универсальных инструментов для различных ниш, адаптированные под мобильные устройства.

## 📁 Структура проекта

```
├── index.html          👈 Главная страница с навигацией
├── gewinn.html         💰 Калькулятор прибыли
├── kasse.html          🏪 Кассовый отчёт  
├── solar.html          ☀️  Расчёт солнечного кабеля
├── physio.html         🩺 Журнал физиотерапии
└── README.md           (этот файл)
```

## 🚀 Быстрый старт

### На ПК
1. Скачайте все файлы в одну папку
2. Откройте **index.html** в браузере
3. Выбирайте нужный калькулятор

### На телефоне  
1. Загрузите файлы на свой телефон (через облако, Email, AirDrop и т. д.)
2. Откройте **index.html** через приложение браузера
3. Сохраните ярлык на главный экран для быстрого доступа

## 📲 Адаптивность

- ✅ **Мобильные**: оптимизирована для экранов от 320px (iPhone SE)
- ✅ **Планшеты**: полная поддержка 768px–1024px
- ✅ **Десктоп**: удобный интерфейс на 1200px+

### Особенности для мобильных:
- Крупные кнопки (легко тапать)
- Вертикальная раскладка на узких экранах
- Минимальные тапы для ввода данных
- Быстрая загрузка (нет сетевых запросов)

## 💰 Калькулятор прибыли

**Файл:** `gewinn.html`

### Что считает:
- Прибыль по артикулам
- НДС (19%, 0%, любое значение)
- Рекламные расходы (% от продаж)
- Маржу и наценку

### Функции:
- ✅ Импорт из Excel/CSV
- ✅ Экспорт в CSV
- ✅ Печать отчётов
- ✅ Дублирование артикулов
- ✅ Сохранение в браузере (локально)

### Пример использования:
1. Добавьте артикулы (или импортируйте из Excel)
2. Введите: номер, название, себестоимость (нетто), кол-во, цена продажи (брутто)
3. Калькулятор покажет прибыль и маржу
4. Экспортируйте отчёт в CSV для Excel

## 🏪 Кассовый отчёт

**Файл:** `kasse.html`

### Что делает:
- Пересчёт наличных денег
- Автоматический подсчёт по номиналам
- Сверка Ist (есть) vs Soll (должно быть)
- Кассовая книга с позициями

### Функции:
- ✅ Реальное время (часы/дата)
- ✅ Ввод кол-ва купюр и монет
- ✅ Поддержка Euro (€) и других валют  
- ✅ История записей в кассовую книгу
- ✅ Печать отчёта

### Пример использования:
1. Укажите кассу и кассира
2. Введите начальный остаток (вчера на конец дня)
3. Пересчитайте деньги по номиналам (система сложит автоматически)
4. Добавляйте транзакции в кассовую книгу
5. Система покажет разницу и вердикт (кассой совпадает / не совпадает)

## ☀️ Расчёт солнечного кабеля

**Файл:** `solar.html`

### Что считает:
- Сечение кабеля для солнечных панелей (4 или 6 мм²)
- Падение напряжения
- Потери мощности (%)
- Допустимый ток

### Функции:
- ✅ Готовые профили (Anker, AIKO, JA Solar)
- ✅ Собственные параметры модуля
- ✅ Учёт температуры и длины кабеля
- ✅ Рекомендация «Автомат» или «Вручную»
- ✅ Расчёт экономии за 20 лет

### Пример использования:
1. Выберите устройство (Solarbank, инвертор и т. д.)
2. Выберите солнечный модуль (или введите параметры)
3. Укажите кол-во модулей и длину кабеля
4. Система даст рекомендацию: **4 мм²** или **6 мм²**
5. Расчитает стоимость и потери за 20 лет

## 🩺 Журнал физиотерапии

**Файл:** `physio.html`

### Что делает:
- Ведение картотеки пациентов
- Запись сеансов и процедур
- Отслеживание прогресса лечения
- Анализ результатов терапии
- История всех визитов

### Функции:
- ✅ Профили пациентов с контактами
- ✅ Запись каждого сеанса (дата, время, процедура)
- ✅ Заметки о прогрессе и симптомах
- ✅ Отслеживание результатов
- ✅ Печать отчётов пациента
- ✅ Поиск по пациентам и датам
- ✅ Калькулятор визитов и статистика

### Пример использования:
1. Создайте профиль пациента
2. Добавьте начальный диагноз и цели лечения
3. После каждого сеанса запишите результаты
4. Отслеживайте прогресс по графикам
5. Печатайте отчёты для пациента или документации

## 🔧 Техническая информация

### Браузеры
- Chrome/Edge 80+
- Firefox 75+
- Safari 13+
- Мобильные браузеры (всё работает)

### Требования
- **JavaScript:** включить (в настройках браузера)
- **Локальное хранилище:** желательно (для сохранения данных)

### Безопасность
- Все расчёты выполняются **в браузере**
- Данные **не отправляются** на серверы
- История остаётся **на вашем устройстве**

## 💾 Как сохранять и делиться

### Сохранение результатов

**Gewinn (Прибыль):**
```
Кнопка "📄 Отчёт" → печать или "Сохранить как PDF"
Кнопка "⬇ CSV" → загрузит файл для Excel
```

**Kasse (Касса):**
```
Кнопка "⎙ Абсчлюс" → печать отчёта
Данные хранятся в браузере автоматически
```

**Solar (Кабель):**
```
Кнопка "Копировать результат" → весь расчёт в буфер обмена
Ссылка делится в соцсетях/чатах через URL
```

### Делиться расчётом
1. Сделайте расчёт
2. Скопируйте все файлы друг на друга
3. Откройте `index.html` → проект готов

## 🐛 Если что-то не работает

### На мобильнике не видны цифры
→ Обновите страницу (Ctrl+R или свайп вверх)

### Калькулятор медленно работает
→ Очистите историю браузера (Settings → History → Clear)

### Данные потеряны
→ Локальное хранилище очищено. Сохраняйте результаты в CSV/PDF!

### Не открывается один из файлов
→ Проверьте, что все файлы в одной папке. Откройте index.html первым.
